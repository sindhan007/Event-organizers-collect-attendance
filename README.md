# Gatherwell Event Analytics

Gatherwell is an event analytics platform for organizers who collect attendance and feedback but need a clearer way to evaluate overall event success. The product connects attendance rate, feedback coverage, sentiment, return intent, and engagement into practical recommendations for planning the next event.

## Capstone Project Idea

The platform will help event teams move from disconnected spreadsheets and survey responses to one evidence-based event health view. Organizers will be able to create events, collect attendance and feedback data, compare event performance, identify attendee themes, and turn insights into an action plan.
