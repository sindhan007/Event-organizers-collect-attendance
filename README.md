# Gatherwell Event Analytics

Gatherwell is a mock UX for an event analytics platform that helps organizers connect attendance, feedback, and engagement into a clear measure of event success.

## Mock UX Design

Public Mock UX preview:
https://htmlpreview.github.io/?https://raw.githubusercontent.com/sindhan007/Event-organizers-collect-attendance/feature/mock-ux-design/mock-ux/index.html

GitHub Pages destination:
https://sindhan007.github.io/Event-organizers-collect-attendance/mock-ux/

Source prototype:
https://github.com/sindhan007/Event-organizers-collect-attendance/blob/feature/mock-ux-design/mock-ux/index.html

This clickable mock UX demonstrates the platform's primary screens, navigation flow, and major user journeys: reviewing event health, comparing events, exploring attendee feedback, and turning insights into an action plan for the next event.

Open `mock-ux/index.html` in a browser to explore the prototype locally.
